# 共通ルール（バルク生成サブエージェント）

あなたは `training/.bulk_gen/` 内にのみ書き込みます。**絶対に変更してはいけない**のは
`training/raw/`, `training/processed/`, `training/splits/`, `training/metadata/`,
`training/sft_synthetic_*.jsonl`, アプリ本体コードです。読み取りは可。

## 出力先
- 割り当てられた1ファイルだけに、JSONL を**1回の write で**書き出してください（追記しない）。
- ファイル名・ID接頭辞・割り当てテーマはプロンプトの指定を厳守（他エージェントと衝突しないため）。
- 既存ファイルが存在したら上書きせず、その旨を報告してください。

## 絶対に守る内容（既存仕様より）
- 出目・合計・判定結果を創作しない。描写はプレイヤー行動と状況のみを根拠にする。
  （choice.check には dice/total/outcome を**書かない**。後述）
- 敵HPを動かさない。HP_DELTA はプレイヤーキャラクターにだけ使う。
- context に無い ID / NPC / 場所 / アイテムを参照しない。
- 既存作品の固有名詞を使わない。各シナリオは独立した世界観・固有の名前・固有の展開にする。
- 単純な言い換え・テンプレート量産は禁止。状況・動機・判定結果・結末を毎回変える。
- 日本語として自然で、情景が目に浮かぶ描写を書く（1文だけの短すぎる narrative は不可）。

## 監査について
生成物は封印（seal）→不変スナップショット→既存の品質監査ツール
（`training/tools/quality_system.py score`）へ流れます。監査は inbox を直接読みません。
書き込み途中のファイルは絶対に監査されません。

## 完了報告
書き出したら、ファイルパス・件数・使用したテーマ・気づいたリスクを日本語で報告してください。
